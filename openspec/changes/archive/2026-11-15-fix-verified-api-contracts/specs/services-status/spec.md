# Spec Delta

## MODIFIED Requirements

### Requirement: Статусы сетевых сервисов

Интеграция SHALL предоставлять отдельный двоичный признак включения для каждого поддерживаемого сервиса: SMB/CIFS, NFS, FTP, WebDAV, SSH, SFTP, rsync, SNMP и TFTP. Признак MUST отражать состояние, сообщённое ADM, и MUST NOT изменять настройки сервиса. Запрос состояния каждого сервиса MUST передавать параметры, которых требует контракт ADM: для SMB/CIFS, NFS, FTP, WebDAV и SNMP — параметр `tab` со значением, которое использует интерфейс ADM (`cifs`, `Nfs_Get_Enable`, `general`, `webdav`, `Get`).

#### Scenario: Включённый и выключенный сервис

- **WHEN** ADM сообщает, что SMB включён, а SSH выключен
- **THEN** признак SMB находится в состоянии «включён», а признак SSH — в состоянии «выключен»

#### Scenario: Сервис недоступен на модели

- **WHEN** ADM не возвращает сведений о конкретном сервисе
- **THEN** признак этого сервиса остаётся недоступным, а остальные признаки публикуются как обычно

#### Scenario: Попытка записи

- **WHEN** пользователь пытается изменить состояние признака сервиса из Home Assistant
- **THEN** состояние сервиса на NAS не меняется, поскольку такие сущности не поддерживают управление

### Requirement: Число активных сессий

Интеграция SHALL предоставлять число активных клиентских сессий NAS как числовую сущность и MUST обновлять её в медленном цикле опроса. Запрос списка сессий MUST передавать параметры постраничности, которых требует ADM: `sort`, `ascend`, `start` и `limit`.

#### Scenario: Активные клиенты

- **WHEN** ADM сообщает две активные сессии
- **THEN** сущность числа сессий показывает значение два

#### Scenario: Нет активных сессий

- **WHEN** ADM сообщает отсутствие активных сессий
- **THEN** сущность показывает ноль и остаётся доступной

#### Scenario: Список сессий без параметров постраничности

- **WHEN** в запросе списка сессий отсутствует хотя бы один параметр постраничности
- **THEN** ADM отвечает отказом, сущность числа сессий остаётся недоступной, а остальные сущности медленного цикла публикуются как обычно
