# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Источник истины номера версии — файл `VERSION`; его синхронизируют скрипт `scripts/bump_version.py` и тест `tests/unit/test_version.py`.

## [Unreleased]

### Добавлено

- Перенастройка существующей записи: адрес, порт, режим TLS и учётные данные меняются через меню записи, без удаления устройства и его сущностей. Проверка подключения должна вернуть тот же NAS; отказ получает причину «по этому адресу отвечает другой NAS».

### Исправлено

- Недостаток прав учётной записи ADM распознаётся отдельно: вместо «непредвиденной ошибки» настройка сообщает «недостаточно прав» и подсказывает про группу администраторов. Тело отказа по правам неотличимо от тела истёкшей сессии, поэтому причина подтверждается флагом `isadministrators` из ответа авторизации.
- Английский интерфейс снова на английском: `strings.json` и `translations/en.json` содержали русские строки настройки, перенастройки, переавторизации, ошибок и интервалов опроса, поэтому при языке `en` эти диалоги выходили на русском. Русский текст остался только в `translations/ru.json`; тест `test_english_source_has_no_russian_text` не даёт вернуть кириллицу в исходник строк.

## [0.1.0] - 2026-11-15

### Добавлено

- Интеграция ASUSTOR NAS (ADM) как пользовательский репозиторий HACS: домен `asustor_adm`, настройка через интерфейс, переавторизация при смене пароля.
- Клиент внутреннего HTTP API ADM на порту 8001: form-urlencoded POST, `sid` в query, разбор конверта ответа, одна повторная авторизация по коду `5000`.
- Системные метрики: загрузка процессора, памяти и томов, температура, обороты кулеров, сеть и пользователи онлайн.
- Состояние хранилищ: тома, диски и их SMART, состояние RAID, внешние диски.
- Статус сервисов и приложений ADM, включая активность и задания.
- Обновления прошивки ADM: установленная и доступная версии, сущность обновления.
- Управление питанием: выключение, перезагрузка и сон — только при подтверждённых правах администратора.
- Диагностика с маскированием пароля, `sid`, учётной записи, серийного номера и адресов.
- Переводы интерфейса на английский и русский языки.

### Изменено

- CI ведётся одним файлом `.github/workflows/ci.yml` для GitHub Actions и Forgejo Actions; метка раннера берётся из переменной `CI_RUNNER`.
